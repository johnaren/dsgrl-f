# Self Learning Feature Augmentations with Graphs

An external validation study of the feature augmentation learner by Samy et al. (2024).

The model learns two separate feature augmenter networks and a graph neural network to produce similar latent representations of the augmented views. The model was evaluated on the Cora citation network of machine learning papers.

Ahmed E. Samy, Zekarias T. Kefatoa, Sarunas Girdzijauskasa. 2024. Data-Driven Self-Supervised Graph Representation Learning. [https://arxiv.org/abs/2412.18316]
